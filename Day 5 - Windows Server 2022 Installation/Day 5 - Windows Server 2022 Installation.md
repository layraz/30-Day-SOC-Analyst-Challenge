# Day 5: Windows Server 2022 Installation

#### Step 1: Select Location and Plan

- Type: Shared CPU
- Location: Tokyo, Japan
- Plan: General Purpose (vc2-1c-2gb)
- Disable Automatic Backup

#### Step 2: Configure Software and Deploy Instance

- OS: Windows 2022 Standard x64
- No VPC Network
- Server Hostname: MyDFIR-WIN-100
- Instance Connectivity: Public IPv4

Click on the Console button in Vultr to login to the Windows Server.

Make sure that RDP is exposed to the Internet.
